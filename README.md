# Trabalho AVL

## Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica e tem como objetivo implementar uma **Árvore AVL** utilizando a linguagem de programação C.

A Árvore AVL é uma estrutura de dados que mantém seus elementos organizados e balanceados automaticamente, facilitando as operações de busca, inserção e remoção.

## Funcionalidades

- Inserir elementos na árvore.
- Buscar valores.
- Remover elementos.
- Realizar rotações para manter o balanceamento.
- Exibir os elementos em ordem crescente.
- Mostrar a estrutura visual da árvore.
- Exibir a altura e o fator de balanceamento.

## Tecnologias utilizadas

- Linguagem C
- Visual Studio Code

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Compile o arquivo `main.c` utilizando um compilador C.
4. Execute o programa pelo terminal.

Exemplo de compilação com GCC:

```bash
gcc main.c -o arvore_avl
```

Para executar no Windows:

```bash
arvore_avl.exe
```
